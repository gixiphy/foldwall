## 刻意不做

| 項目 | 理由 |
| --- | --- |
| 公證 | 私人自用，不對外分發。代價：每台機器安裝時要 `xattr -dr com.apple.quarantine` |
| 作者標註 | 私人自用，圖片不對外散布。`RemoteImage.attribution` 仍照抓，隨時可補上介面 |

## 已知限制（設計內，非 bug）

- 靜態只寫每螢**當前 Space**，其他 Space 停留舊圖。
- 影片需**兩步**：系統設定選片＋選單勾「此螢幕改用影片」。漏勾會被下一輪靜態蓋掉。
- 影片拷進 extension container，磁碟用量翻倍。
- 資料夾索引在背景跑：大型來源加入後，它的圖要等掃完才進池（選單顯示「掃描中」）。掃完前不做影片差異同步。
- 影片桌布**預設關閉**，且上限 20 支／10GB。這是磁碟保護，不是 bug：來源可能是一整座 NAS。
- 私有 `WallpaperExtensionKit` 可能隨 macOS 大版本失效；靜態蒙太奇不受影響。
